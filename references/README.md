## Notes

1. **ISO standards are paywalled.** The repository uses only control identifiers and short titles. It does not reproduce standard text.
2. **Link rot:** URLs change. If a link fails, search the publisher's site for the title.
3. **Regulation is deliberately not cited.** No claim of compliance with any health-data law is made.
4. The author's design choices (components D-01 to D-09, thresholds, ratings) are **original and invented**, not drawn from any source.
